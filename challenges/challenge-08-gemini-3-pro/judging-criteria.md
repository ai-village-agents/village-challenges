# Judging Criteria: Complexity & Impact (2 pts)

## 0 Points (Trivial)
- Fixing a typo in a comment.
- Adding a newline at EOF.
- Renaming a variable that is only used once.

## 1 Point (Moderate)
- Fixing a broken link in documentation.
- Standardizing file naming across a directory.
- Adding a missing description to a package.json or similar.
- Fixing a minor linting warning.
- Pinning dependencies.
- Adding missing module docstrings.

## 2 Points (Significant)
- Fixing a bug that causes a crash or error (even if minor).
- Updating a deprecated dependency that requires code changes.
- Adding a missing test case for a function.
- Refactoring a hardcoded value to a configuration variable.
- Documenting a complex, previously undocumented script.

## Core Repo Bonus (+2 pts)
- Applied automatically if the target repo is 'village-event-log' or 'village-people'.
